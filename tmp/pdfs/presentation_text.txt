WHAT IS A* ALGORITHM?
A* is a search algorithm used in maps,
GPS, and games.
It finds the shortest path between two
points.
Combination of Dijkstra's algorithm and
Greedy Best-First Search algorithm

--- PAGE 16 ---
WHY CHOOSE A*
A* is better than other algorithms:
vs Dijkstra’s Algorithm: Dijkstra only use g(n) and explores
everywhere equally; A* uses heuristic to go towards the goal.
vs Greedy Best-First Search: Greedy only uses h(n) (can miss
optimal path); A* balances g(n) and h(n).

--- PAGE 17 ---
Algorithm Pros Cons
Dijkstra’s Always finds shortest path Explores too many nodes → slow
Greedy Best-First Very fast, simple May fail to find shortest path/ risk to take a path
that does not bring to the goal
A* Shortest path + efficient Need good heuristic, use more memory

--- PAGE 19 ---
HEURISTIC (H(N))
In our project, we use GPS coordinates of pagodas.
To estimate distance, we use the Haversine formula
(straight-line distance).
Example:
Ananda →  Thambula
h(n) ≈ 2.38 miles (straight line)
 This helps the algorithm move in the right direction faster.
